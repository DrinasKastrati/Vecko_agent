**Findings and repairs.** Severity reflects the faulty behavior and potential impact, not evidence that a particular historical loss occurred.

| ID | Severity | Root cause, impact, and repair | Affected files/components |
|---|---|---|---|
| A01 | P0 | Several writers treated unreadable/corrupt state as an empty initial database; direct truncating writes could leave partial files. Strict reads now default only on ENOENT, validate writer structures, and use atomic file replacement. Existing corrupt input is retained for recovery. | New `state-io.mjs`; prices/history/backfill, news, alerts, queue, push receipt and subscription writers |
| A02 | P1 | Concurrent main writers plus `-X theirs` could silently discard the other side of state changes. All eight main-writing workflows now share a queue and check out current main after waiting. External collisions use ordinary rebase and validation, failing visibly on conflicts. | prices, news, movers, monitor, dashboard, auto_merge, analys_queue, push_subscribe workflows |
| A03 | P1 | Auto-merge omitted effective DOM coverage, did not enforce append-only against the pre-merge database, and could publish failed/stale generated output. It now installs the existing test dependency, runs full gates, rebuilds generated data, and revalidates after rebases. Deleting a merged source branch requires its expected SHA, preserving newer commits. Already-removed queued branches are skipped. | `auto_merge.yml`, `test.yml` |
| A04 | P1 | Unicode minus signs were dropped by percentage parsing. Five Nordic weekly accumulated returns appeared as +0.81% instead of −0.81%, and one US value as +2.87% instead of −2.87%. Normalize the sign and regenerate the dashboard. | `assets/vparse.js`, generated `state/dashboard.json` |
| A05 | P1 | Markdown sanitization could admit dangerous URLs/foreign elements, and an AVVAKTA reason was inserted unescaped. Use an HTML/attribute/protocol allowlist, exclude foreign namespaces, escape the reason, and avoid building selectors from untrusted hashes. | `assets/app.js`, `assets/vrender.js` |
| A06 | P1 | Decision alpha counted benchmark bars independently, allowing different end dates; expired decision dates could move to the first retained quote. Require matching dated endpoints and reject expired anchors. Independent sample counts now require windows in both comparison groups. | `decision_eval.mjs`, generated `state/decision_eval.json` |
| A07 | P1 | Backtest MA gates used data unavailable at entry and could permit entry with missing MA data. Gates now use information available at each arm's entry and block without required history. Earnings test halves no longer share the midpoint event. | `backtest.mjs`, `backtest-earnings.mjs` |
| A08 | P1 | Partial push failures were marked completed, permanently dropping delivery to failed devices. Save successful endpoints per event, retry only unsuccessful devices, and persist receipts before reporting the failed workflow step. | `push-notify.mjs`, `monitor.yml` |

| A11 | P2 | Local fill edits could partially save before cancellation, silently fail on quota, overwrite corrupt storage, or calculate a full return from mismatched quantities. | A12 | P2 | Per-symbol earnings failures erased known upcoming events; stale countdowns and past Friday events could appear current. Symbol identity/history recovery needs domain review; the audit did not invent prices or change the investment universe. Existing proxy-event selection, survivorship bias, fixed FX/cost assumptions, and proof of investment edge remain research limitations, not questions this code audit settles.

Validate the workflow changes on GitHub's Linux/Node 20 runner and test offline/PWA/push behavior on a real device before relying on deployment. Local tests used Node 24 and jsdom, not a real browser or notification service. File replacement is atomic per file, not a multi-file filesystem transaction; Git commits publish complete successful workflow results. Push transport and Git receipt commits are not a single transaction, so a process crash after delivery but before persisting its receipt can still cause a retry. Main's shared workflow queue holds at most 100 pending runs and serializes slow fetches/tests; monitor queue latency after deployment. External writers remain outside that lock and cause visible conflicts rather than silent overwrites.
